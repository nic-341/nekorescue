# ネコ救出作戦！

ビルド不要、外部サービス不要のブラウザゲーム。`index.html` を開いて遊べます。音は最初の操作後に再生されます。スマートフォンでは縦画面がおすすめです。

## GitHub Pages

このフォルダ内の `index.html`、`css/`、`js/`、`assets/` をリポジトリのルートへアップロードし、GitHub の Settings → Pages でそのブランチ・ルートを公開対象に指定してください。すべて相対パスで参照しているため、プロジェクト配下のURLでも動作します。実際の公開はまだ行っていません。

## 操作

金色のピン、ロープ、緑色のスイッチをタップ（PCではクリック・TabとEnterも利用可能）。ヒント、やり直し、ステージ選択、音設定を用意しています。新しいステージはクリアで解放されます。進行と音設定はlocalStorageに保存します。保存が利用できない環境でもそのセッション内では遊べます。

## ステージを追加する

`js/stages.js` に配置データを追加します。座標は420×560。`entities` が物体、`actions` が操作、`route` が猫の移動経路です。`water`、`drop`、`releaseCat` の既存効果を組み合わせるステージはデータだけで追加できます。STAGE 2〜5が具体例です。`target` は変化させる物体ID、`landing` は着地点、`requiresClear` は先に排除する危険のIDです。

新しい種類の挙動は `game.js` の `effectHandlers` に追加し、見た目は `drawEntity`、危険との接触判定は `releaseCat` に追加します。扉・トゲ・ハチの描画用分岐もありますが、扉とスイッチの連動やハチの追跡などは今後の拡張対象です。任意レイアウトの物理シミュレーションではなく、定義した経路とギミックのアニメーションを使う方式です。

ステージ数・解放の上限・一覧はデータ件数に追従します。最終ステージ達成画面の文言は必要に応じて調整してください。

## 音の差し替え

付属のBGM・SEは本ゲーム用の生成音源です。`assets/bgm/stage.wav` はループBGM。`assets/sounds/` 内の `pin`、`water`、`fire`、`extinguish`、`rope`、`impact`、`meow`、`enemy`、`fail`、`clear`、`button` の `.wav` を同名ファイルで置換できます。ファイルが読み込めない場合はWeb Audioの簡易SEへフォールバックします。拡張子を変更する場合は `audio.js` の参照も変更してください。

## ファイル

- `index.html`: 画面・ダイアログ
- `css/style.css`: レスポンシブUI
- `js/stages.js`: 25ステージの配置・操作データ

猫やギミックの画像はCanvas上で描くオリジナル図形です。通信による素材の取得は不要です。

## STAGE 6〜10

6は2か所の消火、7は岩を渡す橋、8は排水口と火への水路切替、9は箱を燃やさず橋を作る手順、10は消火・水路・橋・敵の総合問題です。新しい `redirect` 効果と `valve` / `drain` の描画、`requiresBridge` による岩の落下条件を追加しました。STAGE 5をクリア済みなら、保存データを引き継いでSTAGE 6が解放されます。

更新時は `neko-rescue/` フォルダ全体を同じ場所へアップロードしてください。既存の公開URLは `/nekorescue/neko-rescue/` です。HTMLだけ、あるいはファイルを平らに並べたアップロードでは動きません。

## STAGE 11〜15：考えるパズル

11：一回分の水を残すため、岩で片方の火をふさぎます。12：床のハッチを開いて岩を片付け、猫が通る前に閉めます。13：猫を落下地点から避難させ、岩を転がして消火します。14：水を橋の下の火へ割り当て、別の火は岩でふさぎます。15：共通水路を右、左と切り替えて2つの水を使い、猫で足場スイッチを押して箱を橋にします。

`repeatable: true` は再操作可能なスイッチ、操作の `route` と `pause: true` は猫の途中移動、岩の `seal` は消火、`catDanger` は落下地点の猫との接触、`exitGap` は岩用ハッチ、箱の `requiresPad` は猫で押す足場スイッチです。保存済みクリア記録から次のステージを解放するため、STAGE 10までクリアしたブラウザでは11が遊べます。

## STAGE 16〜20：作り直した中盤のパズル

16：一つの岩を穴に使うと火を消す資源が足りなくなります。17：橋の移動モーターは一回だけです。18：猫で足場スイッチを踏むまでは共通水路を変えられません。19：三つの床を切り替える電池は二回だけです。20：水と岩が各一回、橋モーターも一回、猫による水路の解錠を組み合わせます。

使える回数、閉じている床、共通水路、ロックと足場の接続を画面に表示します。ヒントは3段階で、最初は手掛かり、最後は具体的手順です。ミスによる資源の浪費は、その場で即失敗にせず、猫が残った危険へ進むまで画面上の状態を保ちます。

難易度の設計目安は、1〜10が導入、11〜20が基礎から中盤、21〜35が応用、36〜45が上級、46〜50が最難関です。現時点で収録しているのは25ステージで、26〜50の空データはありません。この版は16〜20を差し替え、既存の進行記録と音設定を引き継ぎます。

## STAGE 21〜25：応用編

21：1つの橋を3つの穴へ順に使い、移動2回を温存します。22：水1回と岩2つを火2か所と敵1匹へ割り当て、共通の3方向分岐を切り替えます。23：A+B、B+Cを連動させる有限回数のレバーを、猫の待機位置に合わせて操作します。24：岩を左の出口へ捨てる操作を、床の3回の切替より先に済ませます。25：資源を割り当て、1つ目の岩で火を消して猫を第2足場へ運び、残した岩を猫が解錠した分岐で敵へ送ります。橋の移動は2回だけです。

`maxUses` はレバーの使用回数です。ロック中のレバーをタップしても回数は減りません。3方向の橋は `bridgeControl.choices`、3方向の岩は `fork.choices` で定義します。今後50を最難関とする段階設計のうち、21〜25は応用へ入る区間です。STAGE 20までクリアした保存データから21を解放します。

## ライフと5ステージ区間セーブ（25.2）

本番はライフ5つ。同じステージのやり直しは3回ごとにライフ1つを消費します。失敗後の再挑戦も1回に含み、失敗演出だけでは減りません。途中のやり直しは確認画面で確定したときに数えます。3回目はライフを1つ減らして同じステージの最初へ戻り、カウンターは0になります。クリアでそのステージのカウンターをリセットします。0になると区間の最初（1・6・11・16・21）へ戻り、ライフ5つで再開します。5、10、15、20、25をクリアすると区間を保存し、ライフを回復します。ページを閉じたり再読み込みした場合も、最後の区間セーブ地点から再開します。残りライフは保存します。

ステージ選択から、クリア済み区間のステージを練習できます。練習ではライフを消費せず、途中で本番へ戻ると本番の猫・ギミック・操作回数・ライフを復元します。本番中の任意ステージへの飛び越しはありません。過去のクリア記録は区間単位で練習の解放へ移行し、到達ステージが属する区間の最初を本番の再開地点にします。音設定は引き継ぎます。

STAGE 23はA（橙）・B（青）・C（紫）の床と配線を対応させました。レバーをタップすると開閉予定の確認画面が出ます。確定するまで床は動かず、レバー回数・ライフも消費しません。ロック中は猫の足場スイッチとの接続を表示します。

25.2: STAGE 23の確認画面を「いま → 押したあと」の床の図に変更。猫の位置、A・B・Cの穴／床、変更対象を表示。盤面上部にも現在の床の状態を図示します。旧3ライフの記録は失った数を保って5ライフへ移行します。

## タイトル画面（25.3）
初めから：本番の区間セーブ、ライフ、やり直し回数を初期化。クリア記録・練習の解放・音設定は保持。既存セーブがある場合は確認を表示。続きから：区間セーブ地点から保存済みライフとやり直し回数で再開。未プレイ時は無効。タイトルへ戻るボタンを追加。

## 操作とステージの改訂（25.4）
やり直しは1手戻すに変更。猫、危険、ピン、水、岩、箱、切替回数を直前の操作前へ復元します。失敗からも戻せます。同じステージで3回使うとライフ1つを消費し、そのステージを最初から再開。ライフ0なら区間の最初へ。操作前とクリア後は無効。練習は無制限に1手戻せます。
17: 中央の足場で橋モーターを解錠。21: 足場で箱の止め具を出し、3つの固定箱を順に受け止めるパズルへ変更。22: 中央で分岐・出口を解錠し、ネズミを倒した岩を出口から捨て、出口を閉じる工程を追加。25: 水路の左右表示、ハサミの操作位置とボタンの間隔を修正。全ステージで箱の横幅を穴幅に合わせ、スイッチに機能名を表示。STAGE 5を「水と岩の合わせ技」に改名。
この節の1手戻す仕様が、上記の旧やり直し説明に優先します。

## 猫の統一（25.5）
タイトルと床切替の説明図の猫は、ゲーム本体のdrawCatで描画した共通画像を使用します。ひげ、縞、首輪、鈴、しっぽ、足まで同じデザインです。外部画像ファイルやサーバーへの依存はありません。

## 猫の選択（25.6）
タイトルの猫を選ぶ・着せ替えるを開くと、今の茶トラと参照画像の茶白トラ・サバ白トラの3匹を絵で選べます。個別の名前は表示しません。毛色7種と模様4種を組み合わせて変更できます。選択はlocalStorageのcatStyleに保存し、新しいゲームでも保持します。ゲーム内・タイトル・説明図は同じ描画処理を使います。js/cats.jsに色とプリセットのデータがあります。参照の2匹はゲームの絵柄に合わせた描画で、画像ファイルの切り抜きではありません。

## 種類→毛色の選択（25.7）
猫の選択をトラ・無地・キジの3種類に変更。種類を選ぶと毛色が表示されます。毛色変更は種類を保ち、種類変更は毛色を保ちます。キジは額・頬・体・しっぽに細かい縞を描き、トラと見分けられるようにしています。選択を保存し、タイトル・ゲーム・説明図に反映します。猫ビーム参照の茶白・サバ白の配色は毛色として残しています。
