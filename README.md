# ネコ救出作戦！

ビルド不要、外部サービス不要のブラウザゲーム。`index.html` を開いて遊べます。音は最初の操作後に再生されます。スマートフォンでは縦画面がおすすめです。

## GitHub Pages

このフォルダ内の `index.html`、`css/`、`js/`、`assets/` をリポジトリのルートへアップロードし、GitHub の Settings → Pages でそのブランチ・ルートを公開対象に指定してください。すべて相対パスで参照しているため、プロジェクト配下のURLでも動作します。実際の公開はまだ行っていません。

## 操作

金色のピン、ロープ、緑色のスイッチをタップ（PCではクリック・TabとEnterも利用可能）。ヒント、やり直し、ステージ選択、音設定を用意しています。新しいステージはクリアで解放されます。進行と音設定はlocalStorageに保存します。保存が利用できない環境でもそのセッション内では遊べます。

## ステージを追加する

`js/stages.js` に配置データを追加します。座標は420×560。`entities` が物体、`actions` が操作、`route` が猫の移動経路です。`water`、`drop`、`releaseCat` の既存効果を組み合わせるステージはデータだけで追加できます。STAGE 2〜5が具体例です。`target` は変化させる物体ID、`landing` は着地点、`requiresClear` は先に排除する危険のIDです。

新しい種類の挙動は `game.js` の `effectHandlers` に追加し、見た目は `drawEntity`、危険との接触判定は `releaseCat` に追加します。扉・トゲ・ハチの描画用分岐もありますが、扉とスイッチの連動やハチの追跡などは今後の拡張対象です。任意レイアウトの物理シミュレーションではなく、定義した経路とギミックのアニメーションを使う方式です。

ステージ数・解放の上限・一覧はデータ件数に追従します。最終ステージ達成画面の文言は必要に応じて調整してください。

## 音の差し替え

付属のBGM・SEは本ゲーム用の生成音源です。`assets/bgm/stage.wav` はループBGM。`assets/sounds/` 内の `pin`、`water`、`fire`、`extinguish`、`rope`、`impact`、`meow`、`enemy`、`fail`、`clear`、`button` の `.wav` を同名ファイルで置換できます。ファイルが読み込めない場合はWeb Audioの簡易SEへフォールバックします。拡張子を変更する場合は `audio.js` の参照も変更してください。

## ファイル

- `index.html`: 画面・ダイアログ
- `css/style.css`: レスポンシブUI
- `js/stages.js`: 5ステージの配置・操作データ
- `js/game.js`: 進行、描画、アニメーション、保存
- `js/audio.js`: BGM、SE、音量設定
- `assets/bgm/`、`assets/sounds/`: 同梱音声

猫やギミックの画像はCanvas上で描くオリジナル図形です。通信による素材の取得は不要です。
